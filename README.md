## Voxi0's College Projects
This is just a central repository to hold the code for all the projects I make for college. Written in Rust of course.

### Nix Users
A flake is provided which defines a development shell installing nightly Rust using [Fenix](https://github.com/nix-community/fenix) to make life easier. Just do `nix develop` in the root directory where the flake sits or just provide a path to the command so it can find the flake.
